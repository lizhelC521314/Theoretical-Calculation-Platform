# 普通操作版（标准版）交付方案

## Context

当前软件为「科研版」，面向工程师/研究人员，包含公式推导、符号说明、数据导入、可信资产校准等能力。现需在**同一代码库**上增加面向普通操作人员的「标准版」独立安装包：

- 界面简洁，只保留日常够用的功能
- 不展示公式的详细解释（公式说明栏整体隐藏）
- 不提供任何数据导入入口
- 保留：查询、计算、项目创建、导出计算书、导出试验报告原件副本、导出 CAE 分析报告原件副本
- 用户已确认：材料检索、知识经验库、历史对比继续保留；交付方式为独立安装包，可与科研版共存

两版共用业务逻辑与数据目录，仅通过构建模式（Vite `--mode standard`）控制界面裁剪，科研版行为不变。

## 非目标

- 不实现报告摘要生成（导出即原件副本）
- 不改动数据库结构、计算内核、报告计算书模板
- 不新增用户角色体系，登录逻辑沿用现有管理员/工程师

## 八、标准版内容准则（后续迭代必须遵循）

1. **公式简介控制在 50 字以内**：只说明该公式的主要用途，不写参数枚举、建模步骤与公式推导。文案统一维护在 [briefs.ts](file:///e:/TRAECode/CTR_CODE/src/formula/briefs.ts)，公式库卡片在标准版只显示精简文案；新增公式时必须同步补充对应条目，缺失时自动截取摘要首句并压到 50 字以内。
2. **计算正文必须显示示意图**：公式若定义了 `diagram`，标准版计算页须在结果栏顶部展示「计算简图」，帮助操作者理解输入与结果的关系；无示意图的公式不占位。
3. **不展示科研性内容**：公式说明栏、LaTeX 公式明细、符号表、假设、推导、敏感性分析在标准版一律隐藏。
4. **参数输入只保留参考范围**：每个参数仅显示名称、符号、输入控件；若定义了建议取值范围（`min`/`max`），在控件下方显示「参考范围：[下限, 上限] 单位」，其余参数说明、提示文案与悬浮说明一律不显示；无参考范围的参数不再显示任何附加说明。
5. **不提供数据导入入口**：试验报告、CAE 报告、材料数据的导入与入库校准页面在标准版不出现于导航，也不得从其他页面跳转进入。
6. **保留的日常能力**：查询、计算、项目创建与归档、导出计算书、导出试验报告原件副本、导出 CAE 分析报告原件副本。
