字段定义与校验规则（设计说明）

字段分组

  • 标识与来源：牌号*、系列号*、供应商（仅常规材料）
  • 工况：温度*（°C）
  • 基础物性：密度、泊松比、弹性模量（后两项中密度与模量属于常规材料）
  • 力学性能：抗拉强度、破坏应变（仅常规材料）
  • 曲线数据：应力应变曲线、疲劳寿命曲线（两类材料都有）

必填与唯一键

  • 必填：牌号、系列号、温度，两类材料一致
  • 唯一键：材料类型 + 牌号 + 系列号 + 温度
  • 比较前统一去空格、英文转小写、温度保留 1 位小数
  • 空字符串不等于 0：选填数值留空按“无此参数”处理
  • 同一牌号不同温度 = 多条独立记录

曲线数据格式：CSV 两列（首行可为表头），如 0,0、2,150； 内部按 SI 制存储（应变无量纲 ε = %/100，应力 Pa），界面按工程单位展示。
