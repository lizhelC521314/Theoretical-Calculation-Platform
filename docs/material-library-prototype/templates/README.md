# 材料库导入模板说明

本目录提供材料库批量导入用的 CSV 模板，字段名与原型页面保持一致（camelCase）。
两类材料各提供「仅表头空白模板」与「带示例数据的样例」两份文件，另附两类曲线的数据示例。

## 文件清单

| 文件 | 用途 |
| --- | --- |
| `material-conventional-template.csv` | 常规材料空白模板，仅表头，用于正式录入 |
| `material-conventional-sample.csv` | 常规材料样例，4 行数据，含 1 行主键冲突与留空字段 |
| `material-hyperelastic-template.csv` | 超弹性材料空白模板，仅表头，用于正式录入 |
| `material-hyperelastic-sample.csv` | 超弹性材料样例，4 行数据，含 1 行主键冲突与 1 行温度警告 |
| `curve-stress-strain-sample.csv` | 应力应变曲线示例，8 个数据点 |
| `curve-fatigue-sample.csv` | 疲劳寿命曲线示例，5 个数据点 |

## 字段定义：常规材料

| 列名 | 界面字段 | 必填 | 单位 / 取值 | 说明 |
| --- | --- | --- | --- | --- |
| `grade` | 牌号 | 是 | 文本，≤ 40 字符 | 主键之一，不能含 `\ / : * ? " < > |` |
| `series` | 系列号 | 是 | 文本，2–40 字符 | 主键之一 |
| `supplier` | 供应商 | 否 | 文本 | 留空表示未提供 |
| `temperature` | 温度 | 是 | °C，-60 ~ 400 | 主键之一，统一保留 1 位小数 |
| `density` | 密度 | 否 | g/cm³，0.05 ~ 30 | 留空表示无此参数 |
| `poisson` | 泊松比 | 否 | 0.001 ~ 0.499 | 留空表示无此参数 |
| `elasticModulus` | 弹性模量 | 否 | MPa，0.01 ~ 100000 | 留空表示无此参数 |
| `tensileStrength` | 抗拉强度 | 否 | MPa，0.01 ~ 5000 | 留空表示无此参数 |
| `failureStrain` | 破坏应变 | 否 | %，0.01 ~ 1000 | 不得小于应力应变曲线的最大应变 |
| `stressStrainCurve` | 应力应变曲线 | 否 | 曲线文件名或曲线编号 | 留空表示无曲线 |
| `fatigueCurve` | 疲劳寿命曲线 | 否 | 曲线文件名或曲线编号 | 留空表示无曲线 |

## 字段定义：超弹性材料

| 列名 | 界面字段 | 必填 | 单位 / 取值 | 说明 |
| --- | --- | --- | --- | --- |
| `grade` | 牌号 | 是 | 文本，≤ 40 字符 | 主键之一 |
| `series` | 系列号 | 是 | 文本，2–40 字符 | 主键之一 |
| `temperature` | 温度 | 是 | °C，-60 ~ 400 | 主键之一，统一保留 1 位小数；高于 200 °C 触发警告 |
| `poisson` | 泊松比 | 否 | 0.001 ~ 0.499 | 低于 0.4 时触发「偏低」警告 |
| `stressStrainCurve` | 应力应变曲线（单轴） | 否 | 曲线文件名或曲线编号 | 留空会警告「无法拟合超弹性本构」 |
| `fatigueCurve` | 疲劳寿命曲线 | 否 | 曲线文件名或曲线编号 | 留空表示无曲线 |

## 必填与留空规则

- 必填列只有 `grade`、`series`、`temperature` 三列。
- 其余列留空表示「无此参数」，**不要填 0**；0 会被当作真实数值参与校验和计算。
- 温度统一写 1 位小数，例如 `25.0`、`-20.0`、`220.0`。
- 主键为「牌号 + 系列号 + 温度」，三项相同即视为冲突记录。

## 曲线字段的引用方式

- 主表中的 `stressStrainCurve`、`fatigueCurve` 填写「曲线文件名」或「曲线编号」，例如：
  - 文件名：`curve-stress-strain-sample.csv`
  - 曲线编号：`SS-SPCC-25`（约定该曲线文件名为 `SS-SPCC-25.csv`）
- 曲线文件的主文件名即曲线编号；同一曲线被多行材料复用时，各行填写同一编号。
- 曲线 CSV 按表头列名映射，`pointIndex` 仅表示点序号，不参与计算：
  - 应力应变：`pointIndex,strain,stress`，`strain` 单位 %，`stress` 单位 MPa；至少 5 点，应变严格递增且非负。
  - 疲劳寿命：`cycles,stressAmplitude`，`cycles` 为循环次数，`stressAmplitude` 单位 MPa；至少 4 点，寿命严格递增且为正。
- 正式导入时，主表与曲线表按上述编号关联；若后续改为 Excel 工作表方式，可沿用相同的编号规则。

## 示例中刻意设计的校验场景

| 文件 | 行 | 数据 | 预期结果 |
| --- | --- | --- | --- |
| 常规材料样例 | 第 1 行 | `SPCC / 冷轧钢板 / 25.0` | 与库内已有记录主键冲突，演示冲突策略 |
| 常规材料样例 | 第 2–4 行 | 曲线列留空 | 触发「未提供应力应变曲线 / 疲劳寿命曲线」警告 |
| 常规材料样例 | 第 3–4 行 | `supplier`、`failureStrain` 等留空 | 表示无此参数，不按 0 处理 |
| 超弹性材料样例 | 第 1 行 | `EPDM-70 / 密封橡胶 / 23.0` | 与库内已有记录主键冲突 |
| 超弹性材料样例 | 第 2–3 行 | 曲线列留空 | 触发「无法拟合超弹性本构」警告 |
| 超弹性材料样例 | 第 4 行 | `HNBR-60 / 氢化丁腈 / 220.0` | 温度高于 200 °C，触发温区警告 |

样例文件顶部的 `#` 行是旁注，原型解析器会忽略以 `#` 开头的行。用 Excel 打开时会显示为普通行，正式导入前可删除。

## Excel 打开时的注意点

- 文件编码为 **UTF-8 with BOM**，列分隔符为逗号，可直接用 Excel 打开而不乱码。
- 建议通过「数据 → 从文本/CSV」导入，并确认分隔符为逗号、编码为 UTF-8。
- 不要新增标题行、合并单元格或调整列顺序；表头需保持首行且列名与模板完全一致。
- 温度列建议设置数字格式为 `0.0`，避免 Excel 把 `25.0` 显示成 `25`。
- 牌号、系列号建议按文本处理，避免 Excel 自动转换格式（如把含连字符的牌号识别为日期、丢失前导零）。
- 空单元格就是「无此参数」，请勿用 `0`、`-`、`N/A` 代替空值。

## 与原型页面校验的对齐

数值范围、必填项、曲线点数要求与原型页面的校验规则一致；导入后仍会在预览步骤执行逐行校验，冲突行需要选择冲突策略后才能入库。

本模板表头采用设计中的 camelCase 字段名；原型页面当前的批量导入仍按中文表头匹配，联调时需同步改为 camelCase 表头识别（本次未改动原型代码）。
