# 实验数据入库与模型校准规范（一页版）

> 用途：作为 TraeCode 编程输入。
> 目标：实验报告自动入库 → 与理论计算对比 → 分级为"高精案例 / 偏差案例" → 偏差样本积累到阈值后校准公式，全过程可追溯、可复现、可回滚。

---

## 1. 范围

适用于进气系统（阻力、传递损失、隔振等）实验报告；仿真-only 数据不入库，只作参考。

## 2. 数据分层

| 层 | 内容 | 要求 |
|---|---|---|
| 原始层 | 报告文件（Word/Excel/PDF） | 只读，存 SHA256，不可修改 |
| 结构化层 | 元数据、工况、曲线点 | 单位统一 SI，可查询 |
| 结果层 | 比较指标、分级、根因标签 | 与模型版本绑定 |
| 模型层 | 公式版本、系数、适用范围 | 版本化，可回滚 |

## 3. 数据模型（最小表）

| 表 | 关键字段 |
|---|---|
| experiment | report_id(PK)、product_family、product_model、report_version、test_standard、test_date、operator、lab、file_path、file_hash、unit_system |
| measurement | id(PK)、report_id(FK)、quantity(阻力/TL/隔振)、frequency、value、unit、uncertainty_U95、repeat_no |
| theory_run | model_id(FK)、report_id、input_json、output_json、computed_at |
| comparison | id(PK)、report_id、model_id、metric_json、verdict(PASS/FAIL/SUSPECT)、reviewed_by、reviewed_at |
| case_golden | case_id(PK)、report_id、model_id、applicable_range、approved_by、approved_at |
| case_misfit | case_id(PK)、report_id、model_id、root_cause(边界/测量/模型缺项/单位)、note |
| model_registry | model_id(PK)、version、coefficients_json、calibration_data_ids、metrics_json、status(draft/released/retired) |
| audit_log | id(PK)、entity、entity_id、action、before_json、after_json、actor、timestamp |

## 4. 导入状态机

`UPLOADED → PARSED → QC_PASSED / QC_FAILED → COMPARED → GOLDEN / MISFIT → REVIEWED → PUBLISHED`

每次状态迁移必须写 `audit_log`；`QC_FAILED` 与 `SUSPECT` 退回补测，不入库。

## 5. 元数据必填项

`report_id`、`product_family`、`product_model`、`report_version`、`test_standard`、`test_date`、`operator`、`lab`、`sensor_ids`、`calibration_due`、`temperature`、`humidity`、`altitude`、`flow_rate`、`unit_system`。

缺任一项 → `QC_FAILED`。

## 6. QC 规则

1. 单位统一 SI；dB 类量不参与百分比误差。
2. 重复性：同一工况 ≥3 次，极差/均值 ≤5%，否则 FAIL。
3. 异常点：3σ 或超物理上限 → 标记 SUSPECT，不删除。
4. 传感器校准过期 → FAIL。
5. 曲线点数不足（<5 点/十倍频程）→ SUSPECT。

## 7. 比较判据（核心）

| 数据类型 | 判据 |
|---|---|
| 线性量（压降、力、位移） | `\|model − test\| / \|test\| ≤ 5%` 且 `≤ U95`（取二者较大值） |
| 声学量（TL、声压级） | `\|ΔdB\| = \|model − test\| ≤ 1.5 dB` 且 `≤ U95(dB)`；不允许用"5%" |
| 曲线指标（全部满足才 PASS） | MAPE ≤ 5%、RMSE ≤ 2 dB（声学）/ ≤5%（线性）、峰值频率偏差 ≤5%、带内平均偏差 ≤1.5 dB |

三态输出：`PASS` / `FAIL` / `SUSPECT`（数据质量问题，不算模型偏差）。

## 8. 分流规则

- `PASS` → `case_golden`，须人工审核后才可作推荐值；
- `FAIL` → `case_misfit`，必须打根因标签（边界条件不符 / 测量误差 / 模型缺项 / 单位错误）；
- `SUSPECT` → 退回补测，禁止进入校准集。

## 9. 校准触发与规则

1. 触发：每产品族 `misfit ≥30` 条，或 `golden` 覆盖 <3 个工况；
2. 只允许校准白名单系数（如 α0、R0、k_e、端修正），并限制物理范围；
3. 方法：贝叶斯校准 + 模型偏差项；训练/验证/测试按产品族划分；5 折交叉验证；
4. 发布条件：新模型在 golden 集上 ΔdB ≤1.5 且不劣于旧版本；保留旧版本可回滚；
5. <10 条偏差样本只做案例参考，不更新公式。

## 10. 接口建议（REST）

```text
POST /reports                # multipart 上传，返回 report_id
GET  /reports/{id}/status    # 状态机
POST /comparisons            # {report_id, model_id}
GET  /cases?type=golden|misfit
POST /models/{id}/calibrate  # 触发校准
GET  /audit?entity=...       # 审计查询
```

## 11. MVP 验收标准

1. 能导入 Excel/Word 报告，解析 ≥10 个元数据字段；
2. 能对一条 TL 曲线输出 PASS/FAIL 与 MAPE/RMSE/峰值偏差；
3. golden/misfit 分流人工抽检 20 条，正确率 100%；
4. 全流程 `audit_log` 可查、可回放；
5. 模型发布/回滚可用。
